# Homebrew tap

Install DeepSeek Clock on an Apple Silicon Mac running macOS 13 or later:

```sh
brew install --cask jaibhasin/tap/deepseek-clock
```

Open DeepSeek Clock from Applications after installing.
The app is not notarized, so macOS may require approval in System Settings > Privacy & Security on first launch.

To update:

```sh
brew update
brew upgrade --cask deepseek-clock
```
